# Swiggy India Menu Data – Exploratory Data Analysis (EDA)

This project performs an in-depth Exploratory Data Analysis (EDA) on Swiggy’s India-wide menu dataset to understand food pricing, restaurant patterns, cuisines, and city-level trends. The analysis is carried out using Python and popular data analysis libraries.

---

## 📂 Dataset

- **File:** `swiggy_all_menus_india.csv`
- **Description:**  
  The dataset contains menu-level information from Swiggy restaurants across India, including:
  - Restaurant names
  - City and location details
  - Cuisine types
  - Menu items
  - Item prices
  - Category information

---

## 🎯 Objectives

The main goals of this analysis are:
- Understand pricing distribution of food items across cities
- Identify popular cuisines and restaurant trends
- Analyze cost variations between different food categories
- Explore city-wise and restaurant-wise patterns
- Perform data cleaning and preprocessing on real-world food delivery data

---

## 🛠️ Tools & Technologies Used

- **Python**
- **Jupyter Notebook**
- **Libraries:**
  - pandas
  - numpy
  - matplotlib
  - seaborn

---

## 📊 Key Analysis Performed

- Data cleaning and handling missing values
- Price distribution analysis
- City-wise and cuisine-wise comparisons
- Identifying most common food categories
- Visualization of trends using charts and plots
